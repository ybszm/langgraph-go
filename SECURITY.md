# Security Policy

## Supported versions

Security fixes are applied to the latest revision of the default branch. No
long-term support release line is currently maintained.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature under the repository Security tab.

Include a minimal reproduction, affected package and revision, impact, and any
known mitigation. Reports will be acknowledged on a best-effort basis.

Never include production credentials, personal data, or live service endpoints
in a report or reproduction.
